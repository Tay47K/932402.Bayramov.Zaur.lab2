# Лабораторная работа №2, вариант 14: «Дизайнер и визуализатор»

Страница-портфолио из ЛР №1, оформленная с помощью CSS.

## Структура

- `index.html` — разметка страницы
- `style.css` — основной внешний стиль
- `bg.svg` — фоновое изображение для параллакса
- `avatar.svg` — аватар

## Что реализовано

- Внешний файл `style.css`, переменные в `:root` (основной цвет — пастельно-розовый, акцент — тёмно-серый, шрифты Tenor Sans и Manrope)
- Один inline-стиль (`height: 300px` у секции «Демо позиционирования»)
- Внутренний блок `<style>` для списков (квадратные маркеры, римские цифры, отступы)
- Позиционирование: `static`, `relative`, `absolute` (бейдж «Новое»)
- Псевдоклассы `:hover`, `:active`, `:focus`, `:visited` для ссылок, полей формы и кнопки
- Параллакс-фон (`background-attachment: fixed` и сдвиг `background-position` при наведении на секции)
- Затемнение страницы при фокусе в поле формы (`:has()` и `body::after`)
- Контраст текста не ниже 4.5:1
- Адаптивная вёрстка (проверено на 375, 768 и 1366 px)

## Запуск

Откройте `index.html` в браузере. Все файлы должны лежать в одной папке.

## Примечание

Форма статичная, кнопка «Отправить» ничего не отправляет.
