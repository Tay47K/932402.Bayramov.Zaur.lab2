# Лабораторная работа №2. Базовые и продвинутые возможности CSS

**Тема (вариант 14):** Дизайнер и визуализатор — параллакс-эффект для фона

## Описание

Страница «О себе» из ЛР №1, оформленная с помощью CSS: внешний файл, inline-стиль и внутренний блок стилей.

## Реализовано

- Основной стиль подключён внешним файлом `style.css`
- Inline-стиль: `height: 300px` у секции «Проекты»
- Внутренний блок `<style>` в `<head>`: оформление маркеров и отступов списков
- CSS-переменные: `--main-color` (пастельно-розовый), `--accent-color` (тёмно-серый)
- Лёгкий параллакс-эффект: `background-attachment: fixed` + смещение `background-position` при наведении на разные секции (header / main / aside)
- Затемнение фона страницы при `:focus` на полях формы

## Валидация

Код проверен на [W3C Validator](https://validator.w3.org/).
